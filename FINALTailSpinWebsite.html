01 // Architectural Configuration

System Architecture

The platform splits core operations into isolated modules. Power and communication cross a custom mechanical rotation slip ring, allowing high-speed pixel calculations to perform independently of raw electric motor velocity control.

"Persistence of Vision (POV) displays exploit the human eye's natural processing lag to form stable mid-air floating arrays from simple high-speed moving lines."

// TOPOLOGY SIGNAL AND CURRENT ROUTING FLOW

STAGE 01 // HUMAN MACHINE INTERFACE

Web Application Interface

Accepts standard cartesian files, resamples them into polar configurations, and packages them down to single files under 1MB.

STAGE 02 // COMMUNICATIONS PIPELINE

Nordic UART Wireless Layer

Streams coordinate packages asynchronously via a Bluetooth Low Energy (BLE) link to the rotating hub controller.

STAGE 03 // DETACHED PROCESSING MODULES

Dual Raspberry Pi Pico W Configuration

LED Driver Pico: Decodes frames, slices them into pixel lines, and feeds data streams directly into the blade strips.
Motor Driver Pico: Tracks physical rotational feedback through hardware encoder ISRs, stabilizing velocity profiles over 20 kHz PWM channels.

02 // Physical Specifications

Hardware Systems

// SUB-ASSEMBLY 01

Custom PCB Blades

Features two independent 8-inch high-frequency circuit boards that join together to form a balanced 16-inch rotating diameter.

  • • 80 RGB LEDs per blade (160 total)
  • • Ultra-compact 1.5x1.5mm packages
  • • Integrated onboard 5V level shifter
  • • Inline serial data layout configuration
// SUB-ASSEMBLY 02

Electrical Interface

Employs a split-voltage power delivery layout designed to sustain logic currents across moving joint components without inducing processing voltage dips.

  • • Dual-rail supply: 24V motor / 5V logic
  • • Solid copper ring contacts
  • • Tensioned aluminum leaf springs
  • • Protective diodes & decoupling caps
// SUB-ASSEMBLY 03

Chassis & Kinematics

A modular structural framing system built entirely out of robust, rigid plastic components to isolate internal logic boards from mechanical vibrations.

  • • Fully 3D-printed in rigid PLA
  • • High-torque 24V BLDC motor
  • • Native 1600 RPM geared to 600 RPM
  • • Vibrational dampening rubber foot pads

05 // System Assessment & Roadmap

Project Evaluation & Evolution

Structural Strengths

  • // SOURCING COMPLIANCE Assembled entirely from cost-effective, readily available stock components and open development workflows.
  • // VELOCITY STABILIZATION Maintains a steady 600 RPM rotation speed using robust PID loops with active error integration prevention.
  • // HOUSING RIGIDITY Structural components are printed in tough PLA plastic with base dampeners to isolate physical vibrations.

System Weaknesses

  • // POWER INCONSISTENCIES Intermittent leaf-spring contacts can trigger occasional control board resets or drop ongoing data transfers.
  • // POSITION CORRECTION DRIFT Operating without active angular sensor orientation causes the projected graphic plane to drift slightly over time.
  • // RESOLUTION DENSITY CEILING The simple 16-slice polar mapping scheme restricts the reproduction of intricate, high-detail shapes.

// STRATEGIC ENGINEERING EVOLUTION ROADMAP

UPGRADE 01 //

Parallel LED Data Paths

Migrate to multi-channel driven or clocked LED lines to support richer, denser pixel distributions per blade.

UPGRADE 02 //

Optical IR Positioning

Incorporate specialized infrared optical indexing hardware to calibrate slice positioning and eliminate drift.

UPGRADE 03 //

Enclosed Liquid Slip Rings

Replace friction-based copper leaves with sealed commercial assemblies to guarantee continuous electrical routing.

UPGRADE 04 //

Thickened Base Casing

Increase the wall thickness of modular 3D motor housings to improve sound dampening and reduce acoustic signatures.
